# 工程票 M7.3：幅度判据改成结构的

2026-08-07 立。前置：M6 语义审计、M4.2 rank_pct、M7.1。
触发它的是真实模型**连续七轮**被同一条诊断拦下。

## 事实

M7.1 把累积的语义错配码送进了提示词（已逐字验证：重建的提示词与账本记录的字符数
逐位一致，其中含 `magnitude_vs_signed_label` 及其解释）。模型收到了，也**照做了**：
它立刻用上了刚加的 `rank_pct`，并把特征改成

```
ret    = window(commodity_bar, log_return, sum, 1 日)
vol    = window(commodity_bar, realised_volatility, mean, 10 日)
scaled = ret ÷ vol
r      = rank_pct(scaled, 40 日, 日采样)
```

即**波动率归一的有符号收益**。分子带符号，这正是对「幅度对方向」的正确回应。

七轮全部被拦下，判决理由一字不差。原因在判据：

```python
haystack = " ".join([feature.mechanism.lower(), feature.feature_id.lower()] + 字段名)
return any(hint in haystack for hint in ("volatility", "abs", "dispersion", "range"))
```

它对**机制散文**做子串匹配。而要表达「按波动率归一」，机制里就必须提到波动率。
模型无法逃出这个判定。七轮里六轮是同一个构造的变体，第七轮换了参数，还是被拦。

这与本会话修掉的几处是同一类错误：诊断本身misfire，却被当成关于特征的实质结论。

## 改法

判据沿 DAG 从**输出步骤**反推，只看字段名与算子，不看散文：

- 叶子步骤：算子属 `{std}`，或字段名含 `volatility` / `abs` / `dispersion` / `range`
  之一，即为量级；
- 派生步骤：**当且仅当其全部输入都是量级时**才是量级。
  一个带方向的输入就足以让输出带方向。

因此 `有符号 ÷ 量级` 仍有方向，而 `量级 ÷ 量级` 是量级。

## 用全部历史规格回测

16 条互异规格全部重算，判定与新规则：

| 判为量级（真阳性，原样保留） | 判为有方向 |
|---|---|
| `rv_innovation_z_1d_vs_14d`（rv 均值） | 4 条 pm 关注度与信念特征 |
| `pm_iran_belief_churn_innov_z`（`std(p)`） | 6 条 `log_return ÷ realised_volatility` |
| `cb_rv_short_over_base_z`（rv ÷ rv） | `pm_iran_trade_arrival_z` |
| `rv_dispersion_ratio_rank_10d`（`std(rv) ÷ mean(rv)`） | `pm_iran_notional_innov_rank_90d` |

**每一条真阳性都保留了**，包括改动前唯一被正确拦下的那条 `std(rv) ÷ mean(rv)`。
被放行的全部是分子带 `log_return` 的构造。这不是把闸门拆了，是把它从散文匹配
换成结构判定。

`AUDIT_VERSION` 由 0.1.0 升至 0.2.0。

## 顺带修掉一份会漂的清单

`IMPLEMENTED_STEP_KINDS` 在 M4.2 新增 `rank_pct` 时没有同步，而它**一声不响** ——
因为它与 `unsupported_step_kinds` 一起全仓没有调用方。这类"声明了却没人读"的东西
正是 M6 票开头点名过的形态（三个角色声明过、全仓引用两次、从没被调用）。

补上 `rank_pct`，并加合同测试钉住它等于「除 `residualise` 之外的全部步骤类型」——
`residualise` 是唯一一个语言里可表达、解释器却抛 `StepNotImplemented` 的类型。
同时在注释里明记它当前没有调用方，比让一份会漂的清单假装在生效好。

## 实测

- `.venv/bin/ruff check .` 通过；`pytest tests/ -q`：**646 通过**（M7.2 后 642 + 4）；
- 新增四条测试：波动率归一的有符号收益必须放行、量级÷量级必须仍被拦、
  机制文字提到波动率但取值是对数收益时结构说了算、清单与解释器一致。

## 本票不做

- 不改 `_MAGNITUDE_HINTS` 的词表本身。它现在只作用于**字段名**，
  而字段名是数据层定义的封闭集合，不是模型可以自由书写的散文；
- 不判定 `notional` / `trades` / `p` 的方向性。现行判据把它们视为有方向，
  这与改动前一致（那四条特征此前都通过了审计并被评价）。是否该把关注度类字段
  归为无方向，是一次语义裁决，另立一票。
