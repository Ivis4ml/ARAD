# 工程票 M9.1：Research Atlas 演化视图（React 应用）

2026-08-06 立。前置：M9 Atlas 最小版本、M4.1 zscore。

## 需求与它自带的陷阱

人类要求：把 Atlas 做成 React 应用，主视图是一条曲线，展示关键指标在迭代中的走势，
每个点是一次策略进化。

**这个需求自带一个会骗人的形状。**旧系统 `ADAR/artifacts/hillclimb/*.json` 的实测
摆在那里：81 次爬山选出的最好 Sharpe 是 2.40，而同一套搜索过程在零假设下的期望是
2.63（该文件自己记录的 `sr_null_ann`）。曲线在涨，实际比噪声还差。只画"每次尝试"
与"running best"两条线的应用，会把选择在噪声上必然产出的形状呈现为"策略在变好"。

因此本票的核心不是画图，是**第三条线**：同样次数的搜索在纯噪声上能达到的水平。

## 三条线与它们的口径

- **每次尝试**：按 verdict 着色，含未读 outcome 的轮次（它们是提案分母的一部分）；
- **running best**：只增不减；
- **零假设带**：`E[max |z|]`（Bailey & López de Prado 近似），n 取本链**已读 outcome**
  的次数。被预检挡下、未读 outcome 的轮次留在图上但不抬高这条带 —— 多重检验的负担
  来自读了多少次结果，不是提了多少个想法。

单侧与双侧必须分清：Sharpe 只朝一个方向挑选，用单侧；|t| 接受任一方向，用双侧。
用错一侧会把零假设水平抬高约 10%。实现以旧系统独立算出的 `sr_null = 0.16595662`
为跨实现核对，误差在 1e-4 以内。

带按检验独立计算，而同族变体高度相关，因此它**偏严**。这一句必须印在图旁边，
否则"没越过带"会被读成"确定无效"。

## 指标：哪些能画，哪些不能

- **|t|**：评价机已有，可画，配零假设带；
- **IC**：本票新增 `information_coefficient`（Spearman + Pearson）。**它是时序 IC，
  不是截面 IC** —— 截面 IC 需要同一时点多个标的，本样本单品种，`product_clusters`
  为 1。叫它 IC 而不注明，读的人会按截面 IC 的直觉理解量级与显著性；
- **Sharpe**：机制照实现（含偏度、峰度、`deflated_sharpe`），但**当前两个 target
  的 label 都不是收益**：`sc_rv_next_session` 是已实现波动，`sc_open_gap_absorption`
  是吸收比例且明确不作可交易主张。因此 `EvaluationRequest.label_is_return` 默认为假，
  Sharpe 返回 `None` 加一条明确理由。给一个能被误读的数字，不如给一个明确的未定义 ——
  与解释器拒绝伪造 zscore 是同一条原则。真 Sharpe 需要一个收益型 target，另立一票
  （M2 自己的注释就写了：开盘价对决策时点不可执行，这里有真问题要解）。

## 谱系：让"迭代"成为账本里的事实

`StudySpec` 新增 `parent_study_id` 与 `change_summary`。没有它们，按判决时间排出来的
一条线只是先后顺序，相邻两点之间没有继承关系，而"策略在演化"这句话无从查证。
应用默认按谱系展开，可切到时间轴；切到时间轴时**不画零假设带**并显式说明原因：
把不同族、不同目标的检验混在一条线上，"看了多少次"的口径不成立。

`run_episode` 新增 `schedule_next` 回调：判决之后按 `next_action` 决定要不要排下一版。
这是环真正闭上的那一段 —— 此前 `NextAction.CREATE_NEW_VERSION` 写进账本却没有任何
东西会去执行它。

## 技术选型

Vite + React + TypeScript，`vite-plugin-singlefile` 构建成**单文件** HTML（JS 与 CSS
全部内联），产物复制到 `src/arad/atlas/app_shell.html` 随包分发。Python 渲染器把投影
以 `<script type="application/json">` 注入 `<head>`。因此：

- 渲染不需要 node，`arad atlas render` 在任何机器上都能跑；
- 页面零网络请求，只读边界仍是物理的；
- 数据注入做 `<` 转义，payload 里的 `</script>` 不能提前结束脚本块（有测试）。

图表手写 SVG，不引图表库。版式取自 `Alpha-Data/docs` 的报告：浅底白面板、等宽标签、
表格数字对齐 —— 目的是让读的人一眼分得清"证据"与"说明"。

外壳缺失时**显式失败**（`AppShellMissing`），不静默回退成一个看起来正常但没有演化
曲线的页面；要静态渲染请显式 `--renderer static`。

## 出口条件与实测

- `arad episode demo --provider lineage`：一条五版演化链，|t| 3.06 → 5.03，
  IC 0.059 → 0.161，零假设带 0.80 → 1.58，每一版都记下改了什么；
- 曲线、running best、零假设带三线俱全，点开任一点展开该版的判决快照；
- 负向测试：无父子关系不得连成一条链；payload 无法闭合 script 标签；外壳缺失大声失败；
- 全仓 ruff 与 pytest 通过。

## 本票不做

- 真 Sharpe（需要收益型 target，另立一票）；
- 截面 IC（需要多标的横截面，属 M5 之后的宇宙扩展）；
- 谱系 DAG 的分叉可视化（当前只画一条链，分叉在下拉里选）。
