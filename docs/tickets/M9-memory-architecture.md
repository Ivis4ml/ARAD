# 工程票 M9：记忆架构 —— 按「知道这件事要付多少代价」分层

2026-08-07 立。前置：M7.1（错配码回传）、M8.2。

## 先把前提摆正：组合无限不等于可以一直找下去

零假设带按 √(2 ln n) 抬升，因此搜索是**有价格的**：

| 检验次数 | 噪声地板 | run4 那条 t = 2.049 的自罚奖励 |
|---|---|---|
| 9 | 1.854 | **+0.195** |
| 25 | 2.276 | −0.227 |
| 100 | 2.766 | −0.717 |
| 1000 | 3.447 | −1.398 |

同一条证据，跑到第 25 次检验时就不再越过地板。不是它变弱了，是我们自己把地板抬上去
的。穷举无限组合等于把地板抬到没有任何真实效应够得着。

**因此记忆的任务不是让模型想出更多主意，而是让它少花检验。**主意是免费的，
检验是唯一稀缺且被定价的资源。

## 事故：提案器没有任何记忆

`feature_spec_locked` **不在** `PROPOSER_VISIBLE_FIELDS` 里。模型看不到自己写过的
任何一条规格，每一轮都从空白开始重新推导。它不是在第 12 轮，**它是把第 1 轮做了 12 遍**。

实测后果：run3 七轮给出七个几乎相同的构造（`sum(log_return) ÷ mean(realised_volatility)`
的变体）；run1 四轮全在 `cand:iran` 族内打转。此前我把后者当作「发散」写进了报告，
那是误读 —— 那是在一个 2 个字段的空间里，没有记忆地重复。

## 三层

**第 0 层（免费）：提案侧。**写过哪些机制与构造、声明过哪些原语缺口、撞过哪些语义
错配码。这些在**读任何 outcome 之前**就已存在，因此泄漏为零是按构造成立的，
不靠事后检查。

**第 1 层（已披露，但说法要改）：消耗账。**分母与地板此前以「统计量」的形式给出。
改为以**报价**的形式渲染进提示词：

```
本族已花掉 9 次检验。噪声地板现在是 1.854，你再提一个会被评价的假设，它变成 1.913。
地板对已有的与将来的全部结论同时生效 —— 多问一次，之前问过的每一个也要按更高的
标准重读。因此不确定值不值得检验时，产出一条原语缺口声明或一条更锐的可证伪条件，
比多花一次检验更有价值。
```

同样一个数，说成价格，决策才会变。它只是 n 的函数，不含任何结果。

**第 2 层（对提案器永久关闭）：结果侧的归纳。**「哪类机制效应更大」恰恰是零假设带在
度量的那个过程，而且更糟 —— `E[max|z|]` 假设独立抽取，被引导的搜索破坏该假设，
而带**不会**为此定价。这一层给人与确定性调度器看。

## 边界由账本强制，不由调用方自觉

第一版写成 `read_events(role=PROPOSER)` 全量读取，立刻被 `CapabilityDenied` 拦下 ——
提案器不允许全量读账本。**这条拦截是对的，不该绕过它。**`audit.py` 开头记着的
教训正是「绝不走 `read_events`」。

因此在账本层开一个**窄口子** `EvidenceLedger.proposer_memory(event_type)`：

- 只放 `feature_spec_locked` 与 `primitive_gap_declared` 两种，其余抛 `CapabilityDenied`；
- 逐字段过 `PROPOSER_VISIBLE_FIELDS`；
- **丢弃 `study_id`**。它是事件的**列**而不是 payload 字段，payload 白名单管不到它；
  留着它，提案器就能把规格与判决一一对上，那正是要挡的东西。有测试钉住这三条。

规格按 `content_id` 排序而不是按时间，因此不额外泄漏「越近的越可能对应哪个判决」。

## 一条无法消除的小样本泄漏，如实记下

族内只有一条规格且只有一条判决时，两者的对应关系是平凡的。这在提案器视图里本来就
存在（判决计数一直可见），本票不加重它，也无法消除它。

## 实测

- `.venv/bin/ruff check .` 通过；`pytest tests/ -q`：**655 通过**（M8.3 后 652 + 3）；
- 新增三条测试：跨 Study 记忆只开两种事件且由账本强制、记忆不带 `study_id` 也不带
  评价机字段（负向用例把 `t_stat`/`slope` 混进 payload，必须被丢掉）、
  报价只是 n 的函数。

## 本票不做

- 第 2 层的任何东西；
- 把记忆按机制族聚类（那需要一个分类器，而分类器本身会成为一个未被计价的选择）。
