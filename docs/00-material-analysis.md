> 本文档汇总 2026-08-05 对全部现有材料的系统性审查结果，是 ARAD 设计的初始事实快照。
> 按决定 0002：数据事实的最终权威是 M1 生成的机器 manifest；本文数字在 manifest
> 确认前视为 provisional（其中 909 交易日、tick schema、财联社覆盖率等已经过
> 可复现脚本核验的条目视为 verified，见各节标注）。
> 五个专项审查对象：`autoresearch`（参考架构）、`Alpha-Data`（Polymarket 数据与六轮实验）、
> `ADAR`（旧版因子挖掘系统与方法论文档 v1/v2/v3）、`chinese-commodity`（期货 tick 数据）、
> `Crawler/cls`（财联社新闻数据），另加两份专家方法论文档
> （`Feature Intelligence Layer.docx`、`访谈转文字系统设计.pdf`）。

## 1. 最重要的一个发现：样本约束已经解除

旧系统（ADAR 与 Alpha-Data）的全部研究运行在**数据方交付的 125 个交易日期货分钟数据**上
（2026-01-05 至 2026-07-13），且该数据"为数据方交付全部，无法延长"。这个约束造成了三个致命后果：

1. **统计功效不足**：ADAR 注册的检验中 78% 因有效 episode 少于 30 而无法运行；
2. **样本由单一事件主导**：125 天恰好覆盖中东冲突高峰，无法区分机制与情景；
3. **留出集死结**：股指数据止于 2025-12-31，期货数据全部落在已被三轮研究污染的区间内，
   任何候选因子都没有干净的前向数据可以裁决。

而 `chinese-commodity` 数据集实际提供的是：

**2022-11-01 至 2026-07-30，共 909 个交易日、88 个品种的 tick 级（500ms）一档行情。**

与 Polymarket 数据（2022-11-21 起）的重叠约 **890 个交易日**，是旧实验样本的 7 倍。
这意味着：旧系统大量判为 `underpowered` 的假设可以重新开放；样本横跨牛熊与多个宏观情景；
可以划分出真正未被触碰的验证段与留出段。**ARAD 不是"修好 bug 的 ADAR"，
而是"ADAR 的方法论 + 7 倍样本 + tick 粒度 + 新闻控制变量 + 更宽的因子空间"。**

### 2.1 chinese-commodity 要点与六个数据陷阱

- 三种归档形态并存（2022-2024 按年目录、2025-2026.06 根目录月度 zip、2026-07 按日 zip），
  文件名编码两种（CP437 存储的 GBK 与 UTF-8），加载器必须统一处理。
- 15 列统一 schema：`TradingDay, InstrumentID, UpdateTime, UpdateMillisec, LastPrice, Volume,
  BidPrice1, BidVolume1, AskPrice1, AskVolume1, AveragePrice, Turnover, OpenInterest,
  UpperLimitPrice, LowerLimitPrice`。仅一档报价，无五档深度。
- `主力连续_YYYYMMDD.csv` 是当日主力合约的逐字节副本（非拼接序列），但其 `InstrumentID`
  列保留真实合约代码，换月时点可完全从数据自身恢复；跨日不复权，连续合约需自行构造。
- 节假日之外无任何缺口；抽检主力合约无重复时间戳、无缺失值。

六个陷阱（ETL 必须逐一处理）：

1. **郑商所 `Turnover` 不含合约乘数**，且每日有 3 至 15 次累计值倒退，需单独归一化并做单调性修复；
2. **郑商所合约代码为三位数字**（如 `AP610`），存在十年歧义，需结合 `TradingDay` 补齐世纪位；
   且郑商所品种代码大写、其余小写；
3. **交易时段随品种不同**（贵金属夜盘至次日 02:30，农产品至 23:00，郑商所多数品种与金融期货无夜盘），
   需维护品种级时段表；夜盘归属次日交易日；
4. **首行为集合竞价快照**（`Volume` 非零）；
5. **5% 至 8% 的文件是空壳**（挂牌无成交）；
6. **7 个品种名义存在实质无数据**（RI/PM/JR/LR 全空，ZC/WH 接近全空，bb 大部分为空），
   另有 wr/RS/fb 流动性极差；真正可用品种约 **78 至 80 个**；15 个 2023 年后上市品种
   （si/TL/ao/lc/br/ec/PX/SH/PR/lg/ps/ad/bz/PL/op/pd/pt）需注意进入样本的时点，避免生存偏差。

数据集不含（需外部补充或从 tick 聚合）：结算价、仓单库存、基差与现货、会员持仓排名、
**合约规格表**（乘数可由 `AveragePrice/LastPrice` 反推，郑商所除外，应维护静态参照表）。
日线、分钟线、持仓量变化、跨月价差、期限结构均可从 tick 自行聚合，无需外部源。

### 2.2 Polymarket 数据要点

- 两段 tape 设计上首尾相接（M1 实测接缝间隔 248 秒，无重叠），但存在 **15 处列类型冲突**
  （M1 manifest 实测：4 处语义冲突，即 `neg_risk` VARCHAR 对 BOOLEAN 与三个时间戳列
  TIMESTAMPTZ 对 TIMESTAMP，另有 11 处 `large_string` 对 `string` 编码差异），拼接前必须统一；
  `polymarket_chain/analysis/` 是废弃原型，不要接错。
- **negRisk 缺口**：HF 快照从未索引 NegRisk Exchange 合约
  （`0xe2222d279d744050d28e00520010520000310f59`），2024 年美国大选的 2,873 个市场
  只有元数据没有成交记录。自爬段（2026-04-28 起）已包含 negRisk（约占名义额 27.6%）。
  回爬该合约的历史区块可以补齐，目标清单与已验证的爬虫代码
  （`alpha_data/polymarket/chain/`，入口 `scripts/crawl_polymarket_chain.py`）均现成。
- 数据止于 2026-07-14，需用爬虫续爬至今并建立持续采集。
- 磁盘冗余约 128 GiB 可回收（`share/` 109G、`shards/trades/` 19G、`cn_futures.zip`）；
  注意 `shards/resolutions/` 不是冗余。
- 已冻结的登记资产可直接复用：`cn_registry_v3.parquet`（492 市场、836 配对，含时点化
  `admit_ts`）、`tier_registry.parquet`（166 对三档分级）、钱包技能表。

### 2.3 财联社新闻要点

- 实际覆盖 **2020-01-01 至 2026-06-18**（2361 天，零缺失日），894,220 条，比预期更好；
  历史回填完整性经两次独立比对为 99% 至 100%（verified，复现脚本
  `scripts/verify_cls_coverage.py`；爬虫目录中"回填仅 70%"的文档结论与
  Merge-Plan-2 初稿的 72.5% 至 88.6% 抽查同为"多日滚动快照当单日基准"的方法错误）。
  限定：该覆盖率相对"进入过滚动列表（`in_roll=1`）的可见母体"，不是全部新闻母体；
  一致性证据表明未进入滚动列表的比例很低，但不为零。
- `Labels` 是最有价值的结构化字段（82.6% 覆盖，1,075 个标签，含期货市场情报、原油市场动态、
  俄乌冲突快报、中东冲突、有色金属等主题），可直接构造板块级新闻强度因子，无需语言模型。
- **`Reads/Comments/Shares` 是抓取时刻快照，含严重前视偏差**，历史部分不可用于任何因子；
  只有今后用 `cls_realtime.py` 实时采集的才干净。
- 新闻与品种的映射需自建；正文规整（中位 155 字），适合批量处理。
- 缺口：2026-06-19 至今约 7 周需回爬（`python cls_telegraph.py --start 2026-06-19 --end <today>`，
  有断点续跑保护）。
- 战略角色（ADAR-v2 §已论证）：财联社的秒级发布时戳是区分
  "Polymarket 信息经国际市场传导"与"信息本来就在国内公开、Polymarket 只是镜像"
  这两种解释的**必需控制变量**，不是可选项。

## 3. 既有研究结论

### 3.1 Alpha-Data 六轮实验（2,742 项预注册检验）

**否定结论**（全部来自分钟面板管道，样本 125 天）：

- 纯 Polymarket 分钟级方向信号：1,646 项检验 max|t| = 3.994，未达 Bonferroni 门槛 4.285；
- 离散事件信号 636 项检验 max|t| = 2.65；分位成本检验 114 对成本后净收益为正 0 对，
  盈亏平衡倍数中位 47.5（分钟级毛利 1 至 30 bp，成本 100 至 1000 bp）；
- 聪明钱加权无增量（技能钱包仅占主题成交额 2% 至 5%）。

**正面结论**（全部来自窗口级/日频管道，是 ARAD 最重要的因子种子）：

1. **闭市吸收**：国内休市期间 Polymarket 概率变化在开盘跳空被系统性定价
   （油价主题 × SC 相关 0.86，n=37；合并缺口 0.743，n=74）。
   **截面识别**：88 品种按事件暴露度逐日排序，截面 RankIC 0.185（经济先验载荷，HAC t=4.0）
   与 0.261（估计载荷，t=5.0），最高最低五分位开盘前收益差约 100 bp/日。
   限定：同期吸收不可直接交易（开盘价已含信息），但它证明了**横截面暴露度排序这个
   识别框架有效**，条件化变体是最有希望的方向。
2. **中东主题对 SC 的独立增量**：控制 12 个国际基准后 t = 4.94（n=114），约 96 bp/σ。
3. **tension 预测波动**：SC 次日绝对收益 t = −4.40，控制活动度后不变（波动类终点 T5 有效）。
4. **钱包技能真实存在**：大资金钱包前后半段单位盈亏秩相关 0.15 至 0.16，可复用。

**核心教训 C8**：表面 max|t| = 12.85 的"因子"经双腿分解证实全部由期货自身反转腿承载，
Polymarket 腿 t 仅 0.6 至 1.4。任何含标的自身量价腿的复合信号必须做增量分解。

### 3.2 ADAR 四轮研究单元（24 个 Study，全部判 null 或 underpowered）

方法论文档现行版本是 **v2（数据与方法）+ v3（架构与判决）**，v1 仅时间字段分类、
点时约束十二条、泄漏检查清单十二问仍有效。核心资产：

- **五关判据**：可识别（MDE ≤ 经济上限且 n ≥ 30 且 n_eff ≥ 30）、显著（|t| > Bonferroni 门槛）、
  过影响点（删 3 天后同号且保留 30%）、符号正确（与预注册方向一致）、量级可信（|β̂| ≤ 经济上限）。
  四轮里三个"发现"分别被三道不同关卡拦下（控制充分性使 t=3.2 变 −0.17；β 超上限 28.9 倍；
  t=5.48 但 n_eff=1.5）。
- **有效观测数 n_eff（Kish）前置**：厚尾回归量下名义 n 无意义，n_eff 可低到个位数。
- **可行性预检前置于冻结**：功效不足直接判 underpowered，不冻结、不进分母。
- **经济上限事前登记**（`configs/economic_bounds.yaml`），未登记标的判 blocked 并停止：
  "一个能自己决定判据的循环，等价于没有判据"。
- **屏蔽账本**（`blind_ledger` / `assert_blinded`）：给提案器的反馈只含功效类信息
  （n、n_eff、MDE、覆盖率），屏蔽效应类信息（β、t、p、IC），防止 HARKing。
  实证表明功效账本足以引导搜索方向。
- **机制词表与配对校验**（12 项机制、传导步数规则、场所角色 first_price/residual/isolated，
  residual 禁止直接进方向终点）。
- **五类终点** T1 绝对方向 / T2 休市吸收 / T3 内外价差回归 / T4 品种间价差 / T5 波动与尾部，
  每个假设事前声明终点，独立记账。
- **episode 归并**（同一现实事件同一收益日只算一个观测）与市场聚合（需看数据）严格区分，
  混淆两者曾把识别变差虚增 13 倍。
- 123 项回归测试与 HAC/块自助/影响点检查的实现可直接移植。

**"agent 自己就停了"的结构性原因**（必须在 ARAD 根除）：

1. **循环的产出不是它能读的输入**：搜索空间耗尽时 LLM 扩展出新配对清单后无条件 `break`，
   而下一轮读的配对清单是硬编码路径，新清单永远不生效
   （`campaign.json` 实测 `rounds: 0` 而 `expanded: true`）；
2. 记忆库覆盖判定一旦判 null 即永久关闭，没有"数据增加后重新开放"的机制，
   18 格搜索空间用完即止；
3. LLM 调用失败被 `except Exception` 静默吞掉且咨询槽位照常消耗，循环退化为随机搜索而无人知晓；
4. 三个搜索模块的停止语义互不统一（hillclimb 无早停，cognition 有 6 条终止路径）；
5. 仓库中并存两套互不相容的研究范式（事前注册的确证性检验、爬山式夏普最大化），
   后者约 1,150 次实验从未进入前者的多重检验分母。

**已证实的作废代码缺陷**（ARAD 不得复现）：入池筛选用含留出期的全窗口成交额（前视）；
rank/winsor 变换用全段统计量（前视）；夏普只在建仓日上算却按 252 天年化（虚增 1.4 至 2 倍）；
网格重采样右端越界读到开盘后价格；DSR 高阶矩写死正态。

### 3.3 autoresearch 参考架构（Karpathy）

**可原样迁移的模式**：

1. 提示词即程序：无编排器，循环逻辑是 `program.md` 里的编号列表，人类迭代提示词而非代码；
2. git 作状态机：分支 HEAD 即当前最优，提交即接受，`git reset` 即拒绝；
3. 严格可变边界：智能体只改一个文件，评价函数只读且被显式标注为 ground truth；
4. 固定预算而非固定工作量（对应 ARAD：固定回测窗口与固定成本假设）;
5. 上下文节流：输出重定向到日志，只用 grep 提取标量，每次实验只注入约两个数字；
6. 全量记录（results.tsv 含失败）与选择性提交（git 只留成功）分离；
7. NEVER STOP 提示段：列举智能体最可能说出的停止句并逐一禁止，
   在"没有想法了"情形下预先给出继续路径；
8. 针对具体失败模式给提示词打补丁（读堆栈跟踪、用制表符、不用 tee 都是事后修补）。

**不可照搬的局限**：单标量"更低就保留"判据无任何噪声控制
（其自己的记录显示被接受的改进比随机种子波动小一个数量级），
直接照搬到因子挖掘会产出对单一回测窗口过拟合的因子；无停止条件与收敛判据；
单次评价必须控制在分钟级否则需要外部驱动进程。

### 3.4 专家方法论（Feature Intelligence Layer 与访谈规范）

要点已高度浓缩进 ADAR-v2/v3，此处只列 ARAD 直接采用的增量：

- Feature 是完整对象：`economic_hypothesis / expected_direction / forecast_horizon /
  target_universe / data_provenance / failure_conditions` 六要素缺一不可；
- **正交性优先于单因子最优**：新数据源不等于新信息，候选因子必须报告与既有因子库的相似度、
  残差预测能力、组合边际贡献；新闻情绪可能只是价格动量或财报的低质代理，
  未经残差化不得称为新 Alpha；
- 预测周期是因子定义的一部分：每个因子绑定观察窗、发布延迟、执行延迟、预测视界、衰减曲线；
  只在一个极窄周期显著而相邻周期全部失效的因子应怀疑数据挖掘；
- 研究多样性治理：多机制视角提案（供应链、行为、微观结构、语言、网络、事件暴露），
  语义去重，防止输出熵塌缩；
- LLM 生成的数据是派生数据集，必须保存输入快照、prompt 与模型版本、证据引用；
  历史 LLM 特征只能做文档约束的抽取，防止训练知识泄漏未来信息；
- Feature 生命周期状态机：IDEA → HYPOTHESIS_LOCKED → PROTOTYPED → VALIDATING →
  OOS_PASSED → ORTHOGONALITY_PASSED → PRODUCTION → MONITORING → DEGRADED → RETIRED，
  退役不删除，保留失败模式知识；
- Alpha 衰减需分解原因（机制消失、拥挤、数据质量、正交性衰减），不能简单重训；
- 角色隔离：提案者 ≠ 评审者，研究者 ≠ 留出集评估者。

## 4. 对 ARAD 的十条直接设计含义

1. **主战场设在日频横截面**。约 50 个流动品种 × 900 交易日的截面框架下，
   n = 品种 × 日，功效充足；Alpha-Data 唯一 t > 4 的可交易方向性证据
   （暴露度截面 RankIC）正是这个框架。分钟级方向类研究已被 2,742 项检验系统性否定，
   且成本吞噬毛利 47 倍，不再作为主攻方向。
2. **因子空间必须宽于"Polymarket 预测期货"**。tick 数据自身支持完整的商品因子谱系
   （动量、期限结构/展期收益、持仓量变化、成交量、微观结构），有较强文献先验但不构成保证；
   新闻标签支持板块关注度与事件因子；Polymarket 支持暴露度、吸收、波动类因子。
   经典量价因子归 Baseline Control Library，充当正交性对照集与流程演练，
   不计入另类库存目标；另类因子（Polymarket 与新闻）必须证明相对基线的增量。
3. **点时数据层先行**。1.37 TB tick 必须先 ETL 为按品种分区的 Parquet
   （bar 聚合 + 连续合约 + 六陷阱处理），Polymarket 两段 tape 统一类型后拼接，
   新闻转 Parquet 并剔除前视字段。所有表带 `available_time` 语义。
4. **评价机是只读的 ground truth**（对应 `prepare.py`）：五关判据、n_eff/MDE 预检、
   噪声底校准、正交性引擎、成本模型、实验家族记账，冻结加测试，研究循环不得修改。
5. **循环的状态是注册表文件，产出即输入**：假设积压、判决记录、失败档案全部是循环
   每轮开头读取的同一组文件；覆盖判定带"数据增长后重新开放"条件；LLM 失败计数可见。
6. **提案与判决隔离**：提案在只见功效账本与失败档案摘要的子代理中进行
   （Claude Code 子代理天然支持），主循环执行与判决；假设先锁定后检验，
   事后解释一律作为新假设记账。
7. **样本划分可裁决**：discovery 2022-11 至 2024-12，validation 2025-01 至 2025-12，
   holdout 2026-01 至 2026-07（对源自旧研究的假设族标记弱污染），
   前向 holdout 自 2026-07-15 起由持续采集积累；每次冻结记录"该冻结可在何时被何数据裁决"。
8. **噪声底是第一个实验**：任何战役开始前先测量评价指标在随机因子与种子扰动下的分布，
   小于噪声底的改进一律视为无改进（修复 autoresearch 的最大缺陷）。
9. **停止语义显式化**：三层结构（Search Episode 可结束、Study 必须判决、
   Research Service 只能人工暂停）；库存覆盖目标为 5 个另类 production 因子
   （调度优先级而非期限承诺），达到后转入维护优先模式，系统只被人类中断。
10. **数据持续更新是纪律的一部分**：期货 `git pull`、Polymarket 链上续爬、
    财联社回爬加实时采集，三条更新路径写入运行手册；否则复制 ADAR 的留出集死结。
