# 决定 0009：对抗性评审第一梯队（吸收目标升级、多控制残差化、先验种子）

- 日期：2026-08-14
- 状态：已采纳（用户对评审第一梯队明确指示「开工」）
- 触发：对抗性评审判定「方法的边界先于市场的真相被触到」（报告 §9）
- 影响：targets.py 吸收目标 kind；spec/interpreter/codegen 的 residualise；
  FEATURE_SPEC_VERSION 0.5.0、INTERPRETER_VERSION 0.5.0；run25 的方向指令

## 一、休市吸收目标升为 primary

`sc_open_gap_absorption` 由 diagnostic_only 升为 primary。依据：前身研究唯一的
强阳性正是闭市吸收形态（油价主题×SC 相关 0.86，n=37；合并缺口 0.743，n=74），
而本系统 200 个提案只有 2 个用它 —— kind 字段进菜单，"diagnostic" 实质性劝退。
primary 从不意味着可交易（rv 目标同样 tradable_claim=False）：它意味着
「值得花检验预算的问题」。tradable_claim 保持 False（吸收比例不是收益）。

## 二、residualise 支持 1 至 3 个互异控制

依据：先验的「中东增量 t=4.94」是在控制 12 个国际基准后得出的；单控制残差可能
残留共同因子，使发现段虚高、封存段塌陷 —— 与四次封存否决的形态一致。上限三个：
90 个回看样本上的过拟合风险盖过更多控制的解释力。

语义：**单控制路径逐位保持第一版算式**（账本冻结规格必须可复现）；多控制走
正规方程 + 部分主元高斯消元（纯 Python，主元 < 1e-10 判奇异返回 None——含共线）。
门槛：单控制计控制变量互异取值（原样）；多控制计成对样本数 ≥ min_samples，
且任一控制恒定即无定义。解释器与代码生成器逐位一致（合同测试钉住）。

## 三、先验种子经方向通道喂入（零代码）

前身 2,742 项检验的四个阳性种子作为**外部先验**写进 run25 的研究方向指令
（整句入账）。这不违反决定 0006：它封的是本系统自身结果的回流，外部先验的
性质与「人类研究方向」相同。种子措辞须注明来源与样本规模（125 天时代），
并明确它们是待检验的先验、不是结论 —— 尤其 tension→波动的**负号**。
